# Competition Timeline

Fall 2026. Weekly club meetings are on **Tuesdays, 11:15 a.m. – 12:15 p.m.** (SMC's 16-week fall session runs Aug 31 – Dec 22). The competition itself is fully online; Tuesday meetings double as workshops and Q&A.

Status: **draft** — dates are agreed in principle, details still open.

## Schedule

| Date | Event | Notes |
|---|---|---|
| Tue 10/13 | **Kickoff** | Announce the competition, explain Kaggle, rules, registration, team formation. Competition opens if data is ready. |
| Tue 10/20 | Workshop 1 | Python / pandas / Kaggle Notebook basics. Goal: everyone submits a first baseline. |
| Tue 10/27 | Workshop 2 | Exploring the data, understanding the evaluation metric. |
| Tue 11/3 | Workshop 3 | Feature engineering and baseline models. (US election day; classes still in session.) |
| Tue 11/10 | Workshop 4 | Validation and overfitting (public vs. private leaderboard), plus Q&A. |
| Tue 11/17 | Final sprint | Q&A and office hours, model ensembling. |
| **Sun 11/22** | **Submission deadline** | Exact time TBD. Private leaderboard is revealed on Kaggle afterwards. |
| Tue 12/1 | Wrap-up | Winners announced, top teams walk through their solutions. |

Active competition window: 10/13 – 11/22 (6 weeks), plus the 12/1 wrap-up. 11/24 is skipped on purpose (day before Thanksgiving break, expected low attendance). Finals week falls in mid/late December, after the wrap-up.

## Fallback

The data and problem are not finalized yet. If they are not ready by **Sun 10/11**, 10/13 is a kickoff/info session only (registration opens, Kaggle onboarding) and the competition opens on 10/20. The 11/22 deadline stays fixed, so the early phase is compressed rather than the end being pushed into Thanksgiving week.
